# BellaItalia — Digital Restaurant Experience

Website demonstrativo para restaurantes, com identidade visual da Trattoria Bella Vita. A proposta é ajudar estabelecimentos a digitalizar seus cardápios, divulgar pratos e facilitar solicitações de reserva.

## Funcionalidades
- Cardápio e menu gastronômico digital.
- Apresentação do restaurante e suas especialidades.
- Formulário de solicitação de reserva de mesa.
- Interface responsiva.

## Benefícios
Reduz a dependência de cardápios impressos, fortalece a presença digital e facilita o acesso dos clientes às informações do restaurante.

## Tecnologias
HTML5, CSS3 e JavaScript.

## Execução
Abra `index.html` em um navegador.

## Limitações
O formulário de reserva é demonstrativo: não envia solicitações a um servidor nem confirma reservas reais. Uma integração com backend será necessária para uso comercial.
